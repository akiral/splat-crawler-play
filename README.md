# Splat Crawler — playable test build

A WebGPU build of Splat Crawler, a pixel-art roguelike rendered as 3D Gaussian splats.

**Play:** https://akiral.github.io/splat-crawler-play/

This repo only holds the compiled page. It is updated automatically from the private source repo.

- **Browser:** needs WebGPU, so current Chrome, Edge or Safari 26+, or Firefox with WebGPU enabled.
- **Controls:** WASD moves and Q/E rotate. Tab switches between isometric and first person. Drag to orbit the camera, wheel to zoom. Space waits, F drinks a potion, and the number keys 1–6 toggle the debug panel, hybrid vs sorted rendering, palette quantize, HUD, vsync and depth of field.
- **URL options:** `?seed=7`, `&boss`, `&view=fp`, `&debug`, `&nodof`, `&sorted`, `&quantize`.
